# Kherep working rules

The Kherep working rules are installed at user level: the Kherep Codex installer writes them to the user-level `AGENTS.md` in the Codex home (`CODEX_HOME`, by default `~/.codex/AGENTS.md`). Codex loads that file in every session, so this workspace file neither repeats nor imports it.

If the user-level rules are missing, run the Kherep Codex installer instead of copying the rules into this file.

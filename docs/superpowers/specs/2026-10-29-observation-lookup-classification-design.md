# Observation lookup classification (#694)

The authorized change separates lookup failure from evidence of a different space. A thrown or malformed lookup returns `space-lookup-unavailable`; a complete valid response with no matching space returns `space-unresolved`; only a matching key and valid numeric ID differing from canonical authority returns `space-mismatch`. The narrow observation session checks the spaces collection, required row fields, uniqueness and absence of a continuation before trusting absence. The observation-only default transport conservatively refuses any nonempty Link header on the exact spaces endpoint without exposing its contents; other endpoints are unchanged. Case-insensitive key comparison and canonical query trimming preserve the existing broker contract; neighboring keys remain invalid. General broker behavior remains unchanged.

The observation adapter may expose three additional fixed diagnoses: `space-lookup-bindings-missing`, `space-lookup-network-unavailable`, and `space-lookup-timeout`. Presence checks reveal neither binding names nor values. Transport diagnosis reads only allowlisted own data properties for code/name and one cause, never messages, provider content, paths or arbitrary object serialization. Unknown failures keep the generic code. No new tool or diagnostic caller mode is added.

Terminal journal, zero-I/O empty requests, no automatic retries, literal authority, service identity and readback gates remain intact. The scoped updater accepts exact immediate predecessor source bytes from 1532ccdf7d23b35114a2d80bb2b5453e0e4e84a1 in addition to its existing known predecessor; unknown drift still fails before mutation. The flat broker closure and fixed source snapshot include the new helper.

Acceptance requires synthetic RED/GREEN lookup and privacy regressions, exact predecessor upgrade and rollback checks, `npm run typecheck`, `npm run test:bootstrap`, and diff inspection. This change does not restore connectivity or prove native activation. Actual Desktop Luna publication and independent parent readback on both hosts remain separate parent-owned acceptance. A different standalone process is not Desktop evidence. No private input, live installer, inference, publication, push or PR is within this worker's scope.

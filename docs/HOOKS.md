# Hook reference

Every hook Kherep wires, one row each. A hook is wired when one of these sources runs it:

- the Claude settings templates, `claude/settings.user.json` and `claude/settings.project.json`: the hooks under `hooks/`, which start through the hook runtime entry, and the Control Plane hooks, which run through the stable entry point `kherep/control-plane/claude-control-plane-hook.mts`;
- the Codex hook block that `codex/lib/parity-config.mts` renders for the installer;
- the Git hooks that `bootstrap/manifest/files.txt` installs into the bound `core.hooksPath` directory.

`bootstrap/hooks-reference.test.mts` reads those sources and fails when a wired hook has no row here or more than one, when a row names a hook nothing wires, or when a row's cells break the vocabulary below. Add a row in the same change that wires a hook.

**Runtime** names where the hook runs: `Claude`, `Codex`, `Git`, and `Control Plane` for the hooks under `modules/control-plane/node/` or the entry point that runs them. **Event** is the hook event and matcher; for Codex it also names the adapter phase or the dispatcher. **Kind** is one of:

- `blocking guard`: denies the tool call, commit or dispatch when its rule is broken.
- `asks operator`: asks the operator to confirm the call.
- `watcher (warns)`: reports a finding without blocking; the integrity hooks also repair what they find.
- `recorder`: writes a record and never blocks.
- `context`: adds text to the session's context, or wakes it.
- `gate`: stops a turn, or sends a turn or a subagent result back, when a required element is missing; each row says whether it does so only once.

The scripts `claude/hooks/cbm-*` have no row: the Claude template does not wire them. Codex runs its own reminder, `codex-cbm-reminder`.

| Hook | Runtime | Event | Kind | What it does |
|---|---|---|---|---|
| `guard-dispatch` | Claude | PreToolUse, every guard group | blocking guard | Runs the guards of one matcher group in parallel, denies the tool call when a guard denies or cannot run, and starts the integrity re-check when the heartbeat is older than 30 minutes or a guard could not run. |
| `privacy-boundary-guard` | Claude | PreToolUse, all tools | blocking guard | Keeps private paths, private content and local-inference artifacts out of Claude's file tools, the shell, agents, workflows, web and MCP tools, except one unchained run of the approved local runner, and denies direct HTTP to the local model ports. |
| `secret-output-guard` | Claude | PreToolUse, all tools | blocking guard | Blocks shell commands whose output is likely to print a secret value, lets existence checks that print only yes or no through, and accepts a visible `KHEREP_SECRET_OK=1` prefix for a deliberate read. |
| `playwright-file-guard` | Claude, Codex | PreToolUse, all tools (Claude); PreToolUse mcp__playwright__browser_navigate, adapter pre (Codex) | blocking guard | Blocks Playwright browser navigation to a `file://` URL, so local HTML is served over a local HTTP server instead. |
| `dispatch-contract-guard` | Claude | PreToolUse Agent\|Task | blocking guard | Denies an agent dispatch that breaks the dispatch policy, such as one without an agent type or without an explicit model the policy allows, and checks the brief format of an observation dispatch. |
| `commit-guard` | Claude, Codex | PreToolUse Bash (Claude); shell dispatcher, phase pre (Codex) | blocking guard | Blocks a `git commit` whose message breaks the host's commit policy, as early feedback; the Git `commit-msg` hook stays the enforcement boundary. |
| `deploy-guard` | Claude, Codex | PreToolUse Bash (Claude); shell dispatcher, phase pre-no-transcript (Codex) | blocking guard | Blocks production Forge deploys and production deploy wrappers, `forge install` on a named site, force pushes, `kubectl apply` and `scale`, destructive kubectl and Helm verbs and `forge tunnel`, and lets all but `forge tunnel` through with a visible `KHEREP_DEPLOY_AUTH=approved` prefix after the user approved the command. |
| `main-checkout-guard` | Claude, Codex | PreToolUse Bash\|PowerShell (Claude); shell dispatcher, phase pre (Codex) | blocking guard | Blocks a branch switch in the main checkout of a workspace repository, so branch work happens in a linked worktree. |
| `atlassian-destructive-guard` | Claude, Codex | PreToolUse mcp__.*__executeDestructive (Claude); PreToolUse Agent\|spawn_agent\|Task\|Workflow\|WebSearch\|WebFetch\|mcp__.*, adapter pre (Codex) | asks operator | Asks the operator to confirm an Atlassian MCP `executeDestructive` call in Claude; Codex cannot ask, so there the call is denied and the operator runs it. |
| `obs-handback-gate` | Claude | PreToolUse SubagentHandback | blocking guard | Refuses the first malformed claude-obs report handed back through SubagentHandback, once per agent id, with a reason naming the fixed problem; a second malformed handback passes to obs-handback-record. |
| `manifest-watch` | Claude, Codex | PostToolUse, all tools (Claude); post-edit dispatcher (Codex) | watcher (warns) | Shows a diff summary when an edit touches a Forge `manifest.yml`, so a scope addition does not pass unnoticed. |
| `loc-watch` | Claude, Codex | PostToolUse, all tools (Claude); post-edit dispatcher (Codex) | watcher (warns) | Warns when an edit leaves a code file in the workspace longer than 250 lines. |
| `umlaut-translit-watch` | Claude, Codex | PostToolUse, all tools (Claude); post-edit dispatcher (Codex) | watcher (warns) | Warns when an edit writes ASCII-transliterated German umlaut words, such as `fuer` or `ueber`, into a German `.md`, `.xml` or `.txt` file. |
| `simplify-nudge` | Claude, Codex | PostToolUse, all tools (Claude); post-edit dispatcher (Codex) | watcher (warns) | Reminds the session once, after an edit to a code file in the workspace, to run the code-simplifier review on the changed files. |
| `drift-managed-path-watch` | Claude | PostToolUse, all tools | watcher (warns) | Says right after a write that the file is one the drift check manages, and names its versioned source in the repository. |
| `obs-handback-record` | Claude | PostToolUse SubagentHandback | recorder | Checks a `claude-obs` report where SubagentHandback delivers it and records the verdict for `obs-result-check`, with an operator notice for a failed or malformed report. |
| `denied-calls-delivered` | Claude | PostToolUse SubagentHandback | recorder | Marks a delegated worker's denied-call journal as delivered after its handback ran, which `hooks/denied-calls.mts render <agent_id>` reads. |
| `live-hook-integrity` | Claude | SessionStart, all sources; re-check started by `guard-dispatch` | watcher (warns) | Proves that the `.js` and `.mts` files the live settings wire under the Claude home's `hooks/` directory, and the files they import there, can load, restores a missing, empty or unloadable one from the versioned source, and writes the heartbeat only after a fully proven run; the Control Plane entry point and the scripts it runs from the installed source are outside its scope. |
| `orchestra-default` | Claude | SessionStart, all sources | context | Puts a session in the Kherep workspace into Maestro mode and adds the compact Maestro contract once. |
| `runtime-capability-snapshot` | Claude | SessionStart, all sources | context | Adds a secret-free list of the installed and enabled plugins and the configured MCP server names, so the session does not state tool versions from memory. |
| `drift-check-nudge` | Claude | SessionStart, all sources | watcher (warns) | Reports a missing or stale drift-check report or one that shows drift, and starts a new check in the background when the report is missing or stale. |
| `smoke-test-nudge` | Claude | SessionStart, all sources | watcher (warns) | Reports a missing, stale, incomplete or failing smoke-test report, and starts a new run in the background when the report is missing or stale; a failing report is not rerun. |
| `orphan-check-nudge` | Claude | SessionStart, all sources | watcher (warns) | Reports pages of the knowledge space that nothing links to, from the previous read-only check, and starts a new check in the background when the report is missing or stale; it never writes links. |
| `critical-file-integrity` | Claude | SessionStart, all sources | watcher (warns) | Checks the installed Git hooks and `attribution-record.mts` beside them, which no settings file wires, and restores a defective one from the versioned source, measured by its hash at the target. |
| `maestro-discipline` | Claude | UserPromptSubmit | context | Adds a compact Maestro checklist to every prompt in the Kherep workspace, so the routing duties stay in front of the model. |
| `research-first` | Claude | UserPromptSubmit | context | Asks, on every prompt in the workspace, to classify the prompt and to research a relevant one before answering: the knowledge space always, the code graph first inside a git repository. |
| `maestro-banner-gate` | Claude | Stop | gate | Sends a substantial turn in the workspace back once when no assistant message of the session shows the Maestro banner yet. |
| `clq-accept-gate` | Claude | Stop | gate | Sends a delegated turn back once when its last message carries a `Dispatched:` receipt without a real `Evidence:` line, or a receipt naming a build agent without an `Accept: C1` verdict; a turn without a dispatch receipt is never stopped. |
| `observation-stop` | Claude | Stop | gate | Sends a substantial turn in the workspace back once when it neither dispatched `claude-obs` nor opted out with `[obs: none – <reason>]`. |
| `research-stop` | Claude | Stop | gate | Sends a substantial turn in the workspace back once when its transcript shows neither a knowledge-space lookup, plus a code-graph query when it changed files in a repository, nor the opt-out `[research: none - <reason>]`. |
| `obs-result-check` | Claude | SubagentStop claude-obs | gate | Checks the `OBS-RESULT` line of a `claude-obs` result when the subagent stops: a report delivered through SubagentHandback and recorded by `obs-handback-record` passes, even a malformed one, which the recorder already reported; a handback seen only in the transcript is checked and may produce an operator notice, never a block; and a malformed final message is sent back once for correction. |
| `deliver-hook` | Claude, Control Plane | PostToolUse, all tools; UserPromptSubmit; Stop; StopFailure | context | Hands accepted peer messages from the node's inbox to the session, at the prompt and after a tool call inside a running turn, and confirms the delivery at Stop. |
| `attribution-hook` | Claude, Control Plane | PostToolUse Bash\|PowerShell | recorder | Records which session opened which pull request with `gh pr create` in the host-local attribution log, never the command text or its output. |
| `wake-hook` | Claude, Control Plane | SessionStart, UserPromptSubmit and Stop, asyncRewake with timeout 86400 | context | Listens in the background while the session is idle and wakes it when a peer message arrives. |
| `claude-control-plane-hook` | Claude, Control Plane | PostToolUse, all tools and Bash\|PowerShell; SessionStart; UserPromptSubmit; Stop; StopFailure | context | Stable entry point that runs the Control Plane delivery, wake and attribution hooks of the installed source, named by `kherep/control-plane/source.json`, so the Claude hook commands stay the same across upgrades and roots; without a usable pointer it exits 1 with one stderr line and runs nothing. |
| `codex-hook-adapter` | Codex | PreToolUse, every adapted guard entry (phases pre, pre-no-transcript, pre-privacy, pre-intent) | blocking guard | Runs one guard for a Codex hook entry, answers its block with the Codex deny document, and denies the tool call when the guard cannot run or runs past its budget. |
| `codex-privacy-boundary-guard` | Codex | PreToolUse Read\|Grep\|Glob\|Edit\|Write\|MultiEdit\|apply_patch\|Bash\|shell_command\|exec_command\|functions\.exec and Agent\|spawn_agent\|Task\|Workflow\|WebSearch\|WebFetch\|mcp__.*, adapter pre-privacy | blocking guard | Codex counterpart of `privacy-boundary-guard`, built on the same policy libraries: denies file, shell, agent, web and MCP calls that would carry private paths, private content or local-inference artifacts across the boundary. |
| `codex-shell-checks` | Codex | PreToolUse Bash\|shell_command\|exec_command\|functions\.exec | blocking guard | The shell dispatcher: runs `commit-guard`, `deploy-guard` and `main-checkout-guard` within one budget, denies the call when one of them denies or cannot run, and then runs the attribution hook. |
| `codex-control-plane-hook` | Codex, Control Plane | PreToolUse and PostToolUse shell groups (attribution); PostToolUse .* (busy hint); SessionStart, UserPromptSubmit and Stop (delivery) | context | Stable entry point that runs the Control Plane delivery and attribution hooks of the installed source, so the Codex hook commands and their trust hashes stay the same across upgrades. |
| `codex-dispatch-contract-guard` | Codex | PreToolUse Agent\|spawn_agent, adapter pre | blocking guard | Codex counterpart of `dispatch-contract-guard`: denies an agent dispatch whose model or reasoning effort the installed model policy does not allow, and checks the brief format of an observation dispatch. |

| `kherep-maestro-context` | Codex | SessionStart startup\|resume\|clear\|compact; UserPromptSubmit | context | Loads the Kherep Maestro context at session start and adds a short turn checklist to each prompt, inside the Kherep workspace only. |

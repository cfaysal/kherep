# Managed runtime paths parked with reversible backups during installation. One entry per line.
# Paths are relative to the Claude home; a project/ prefix names a workspace file instead.
# A project/ entry lists, after one space, the SHA-256 of every version the installer placed there,
# hashed with CRLF folded to LF: `project/<path> sha256:<hex>[,<hex>...]` (lowercase hex). Only
# matching content is parked; anything else is kept and reported as KEEP. Claude-home entries take no hashes.
# An entry that is absent on the host is skipped. drift-check.sh reports one that is still live, as information.
